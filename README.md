# typehybrid

Monkeytype Analytics x Typing Study Curriculum

TypeHybrid is a web-based typing application designed to combine interactive touch-typing lessons with customizable free testing modes. Built with Next.js, Tailwind CSS, and Web Audio API, it provides real-time typing analytics and an adaptive interface for a seamless practice environment.

Live Demo: https://typehybrid.vercel.app/

## Features

- Study Curriculum: Structured typing modules covering home row, top row, bottom row, and special characters.
- Free Test Mode: Customizable word count and time limit options with varying difficulty levels.
- Visual Keyboard Guide: Interactive visual layout displaying upcoming key presses and error tracking.
- Hand Position Indicator: Real-time visual guide highlighting the correct finger for each key press.
- Dynamic Themes: Includes dark and light themes with adaptive visual contrast for all UI components.
- Audio Feedback: Multiple mechanical keyboard sound profiles powered by Web Audio API.

## Tech Stack

- Framework: Next.js (App Router)
- Styling: Tailwind CSS
- UI Components: Lucide React
- Hosting: Vercel

## Local Development

1. Clone the repository:
   git clone https://github.com/Andikaputh/typehybrid.git

2. Navigate to the project directory:
   cd typehybrid

3. Install dependencies:
   npm install

4. Run the development server:
   npm run dev

5. Open http://localhost:3000 in your browser to view the application.
